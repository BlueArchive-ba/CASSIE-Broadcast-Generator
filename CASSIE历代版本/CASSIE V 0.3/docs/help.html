开始使用

运行项目目录中的 python cassie_play.py，然后打开 http://localhost:8080/cassie_play。

首次运行前建议执行 python diagnostic.py 检查依赖、ffmpeg 和音频素材。

输入内容后可选择“播放广播”试听，或选择“导出WAV”生成文件。播放和导出不能同时进行。

输入规则

  • 单词之间用空格分隔；句号、逗号和顿号建议前后留空格。
  • 系统会自动转为小写，并按照本地 WAV 文件名查找音频。
  • 单个字母会查找 _a.wav 这类文件；alpha 等北约音标会映射到字母音频。
  • 开启“数字朗读”后，整数和小数会按英语数字短语读取；关闭时数字按逐位读取。

可从主界面的“单词查找”打开素材搜索工具，快速确认可用音频文件名。

attention , all personnel . mtf epsilon 11

广播指令

局部指令

  • [stutter:n]word：重复单词开头音频 n 次；也可写 [stutter:n,false]word，只播放卡顿片段，不播放完整单词。
  • [speed:n]word：设置当前单词音高倍率，范围 0.1 到 10。

全局与时间指令

  • [speed_all:n]：设置后续单词音高倍率。
  • [gap:n]：在指令所在位置插入 n 秒等待；n 必须是大于等于 0 的数字。
  • .、,、、：分别插入 0.5、0.2、0.1 秒停顿。
  • [channel:n]：切换后续正文声道，n 为 1 到 8；[channel:stop] 恢复默认声道。
  • [error:n]：从后续正文中随机选择 n 个单词，插入故障音或卡顿；n 为 0 时不插入错误效果。

快捷广播

  • mtf：展开为 mobile task force。
  • [cd:start,end,separator]：生成从 start 到 end 的递增或递减数字序列；separator 可选，默认使用句号停顿。生成的数字仍需对应的数字音频，建议开启数字朗读。
  • [mtf:word1,number1,word2,number2,scp_count]：生成 MTF 入场广播，数字参数必须为正整数。
  • [backup:word]：生成支援单位广播。
  • [warhead:number,start]：生成核弹开始倒计时广播。
  • [warhead:number,resume]：生成核弹恢复倒计时广播。
  • [warhead:any,cancelled]：生成核弹取消广播，取消模式不使用倒计时。
  • [hostile_enter:number,word1,word2,word3]：生成敌对目标进入广播；四个参数都必须填写。
  • [alert:id,once]：播放一次警报；[alert:id,loop]：循环播放警报；[alert:none]：停止警报。

指令必须使用英文半角方括号和逗号。错误参数会显示在终端中，并从广播文本中移除。

界面选项

  • “广播铃声”启用普通背景铃声；“特殊铃声”启用开始和结束铃声。
  • 高级设置可选择 bell_start.wav、bell_end.wav 或 words 目录中的 ic_start.wav、ic_stop.wav。
  • 音高控制播放音高；语速为正数时增加单词之间的间隔，为负数时按比例裁剪首尾静音。
  • “广播空间效果”可调整滤波、压缩、混响、噪声和高音延长。
  • 点击“监听系统音频”可共享屏幕或窗口声音。浏览器通常要求在共享对话框中勾选“共享音频”。

网页无法直接读取操作系统输出设备；系统声音监听依赖浏览器的屏幕音频共享权限。

预设管理

打开“预设管理”后可以保存、加载、删除和导入广播文本。数据保存在项目根目录的 presets.json 中。

常见问题

提示“未找到”

检查 cassie/words/ 是否存在对应的 WAV 文件，或使用“单词查找”页面确认文件名。

没有声音

检查系统输出设备、pygame 初始化和 WAV 文件；运行诊断工具确认依赖与 ffmpeg。

浏览器不允许自动监听系统声音

这是浏览器的权限限制。点击监听按钮后重新选择共享窗口，并勾选共享音频。

如何修改端口

修改 cassie_play.py 最后一行的 port=8080，然后重启服务。
