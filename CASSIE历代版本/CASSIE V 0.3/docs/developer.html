一、总体架构

项目是单进程本地 Web 应用。cassie_play.py 同时包含 Bottle 路由、CASSIETerminal 业务对象、内嵌 HTML/JavaScript 和 pygame/pydub 音频处理。Cheroot 提供多线程 HTTP 服务。

解析层
parse_broadcast_text() 将文本变成队列和错误，不直接播放。
实时层
play_broadcast_stream() 消费队列，管理声道、等待、铃声和清理。
导出层
export_from_queue() 使用 pydub 合成多声道时间线并写 WAV。
资源层
cassie/words 和 cassie/sounds 通过文件名提供音频素材。

二、模块与关键职责

位置/符号职责扩展点
CASSIETerminal保存运行配置、加载预设、管理音频和播放锁。新增配置时同步初始化、前端保存接口和导出参数。
parse_segment()处理单段文本、单词映射、指令前缀、标点和数字。增加指令时返回新的队列项，避免在解析层调用 pygame。
process_number()把数字转换成英语音频词列表。扩展数字范围或负数规则，并为缺失音频提供错误信息。
apply_broadcast_effect()依次执行滤波、增益、压缩、混响、尾音和噪声。添加 pydub 可表达的效果，注意实时播放与导出共用状态。
play_audio_on_channel()加载或处理单个 WAV 后提交到 pygame 声道。保持返回处理后时长，调用方依靠它计算声道时间线。
_export_from_queue_unlocked()为每个声道建立独立 AudioSegment 和位置，再 overlay 混音。增加导出格式或新队列项时同时更新时间线逻辑。
Bottle 路由提供页面、拼写检查、预设、播放、导出和高级设置 API。新 API 应避免直接暴露可变全局状态。

三、数据流与并发

浏览器 POST /play -> play() 获取 play_lock，写入请求选项 -> play_broadcast_stream() -> parse_broadcast_text() -> 队列消费：channel / speed_all / word / number / stutter / pause -> pygame 声道播放 -> 等待声道结束，stop_all_audio()，释放锁 浏览器 POST /export -> export_wav() -> export_from_queue() 获取同一把 play_lock -> _export_from_queue_unlocked() -> pydub 合成并返回 WAV

[gap:n] 会作为队列中的位置标记处理：实时播放消费到它时等待 n 秒，导出则在当前声道时间轴插入 n 秒静音。它不再表示广播开始前的全局等待，也不支持 none 参数。

播放和导出共享 play_lock，因此不会同时操作 pygame 或共享配置。铃声使用第 8 号声道，正文使用 0 到 7 号声道。修改声道分配时需要同步实时播放、警报和导出逻辑。

四、音频实现

变速与音高

音高通过调整 frame rate 后重新采样实现；负语速按静音检测结果裁剪头尾，正语速转成单词之间的等待时间。它不是传统时间拉伸，因此极端倍率会改变听感。

数字短语

数字解析返回 ('number', words)，播放和导出会先拼接组成完整短语，再进行一次处理，避免短音频逐个编码导致音质不一致。

高级效果

效果链由 apply_broadcast_effect() 控制。高音延长使用高通后的 FFT 主频生成指数衰减正弦尾音；噪声由 colorednoise 生成后叠加。新增效果应关注音频声道数、采样率和输出长度。

六、自定义指南

增加单词

把小写 WAV 放入 cassie/words/，文件名即输入词。运行 python test_2.py 更新列表；运行时 load_word_set() 也会扫描目录。

增加铃声

把 WAV 放入 cassie/sounds/。普通背景铃声使用 bg_数字.wav 命名；自定义特殊铃声可通过高级设置的文件名选择。

增加指令

在 parse_segment() 或 parse_broadcast_text() 中加入严格参数校验，返回可序列化的元组队列项，然后分别在实时消费和导出时间线中实现该项。不要只修改其中一条路径。

增加前端设置

添加 HTML 控件、读取和保存字段、后端 GET/POST 字段，并在实时播放与导出请求中传递请求值。共享配置应逐步改为请求快照，以降低多线程请求互相覆盖的风险。

验证建议

  • 运行 python -m py_compile cassie_play.py。
  • 运行 python diagnostic.py 检查环境和素材。
  • 用 SDL_AUDIODRIVER=dummy 做无硬件播放流程测试。
  • 分别验证纯单词、数字、指令、铃声、多声道、导出和异常清理。
