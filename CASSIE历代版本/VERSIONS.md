## V 0.2 — 起点

最早的公开版本。后端与主界面同属一份代码，主界面 HTML 由服务端拼装后返回。

**具备的能力**

- 单词拼接播放与 WAV 导出
- 数字朗读、多声道、广播铃声与特殊铃声
- 广播指令：`mtf`、`[cd:]`、`[warhead:]`、`[backup:]`、`[hostile_enter:]`、
  `[alert]`、`[stutter:]`、`[speed:]`、`[speed_all:]`、`[error:]`、
  `[gap:]`、`[channel:]`
- 预设管理
- 广播空间效果与高级设置面板

**空间效果**用的是多抽头延迟：一串间隔递增的离散回声，高低频同等衰减，
可调项只有延迟、衰减、湿声比例与低通频率。

**这一版没有** HTTP API、中英双语、空间效果的耗时控制档位。

## V 0.3 — 界面与指令扩展

在 0.2 基础上补全页面与指令，并把「文本解析」和「播放 / 导出」在结构上拆开。

**新增**

- 开发者技术文档页与单词查找页
- 把文本解析与播放 / 导出拆成独立环节，便于分别扩展
- 高音尾音增益与铃声锁两项设置
- 帮助文档补齐指令说明

**仍然没有** 反馈网络混响、HTTP API、中英双语、耗时控制档位。

## V 1.0.0 — 混响重写 + 开放 API

变化最大的一版，可以分成五块。

### 1. 更真实的走廊混响

混响从一串离散回声升级为**反馈延迟网络**：多条互质延迟线在回路里互相混合，
反射密度随时间自然增长；回路内做频率相关吸收，高频衰减更快，
低频混响时长严格等于设定值。

可调项增加到：走廊尺度、混响时长（RT60）、高频吸收、扩散度、预延迟、湿声比例。

**另一个关键变化**：混响改为在**整段广播上统一施加**。旧版是每个词各自加一遍，
拖尾会把单词的时间槽撑长；新版开关空间效果都不改变语速与单词间隔。

### 2. 七档耗时控制与两种处理模式

空间效果是整条流程里最重的一步，这一版给它加了完整的开销控制。

| 档 | 名称 | 听感 | 相对耗时 |
|---|---|---|---|
| 0 | 原始 | 与旧版一致 | 1.00x |
| 1 | 轻度 | 拖尾略短 | 0.62x |
| 2 | 中度 | 拖尾明显变短 | 0.39x |
| 3 | 最大加速 | 只保留主要反射 | 0.27x |
| 4 | 激进 | 拖尾很短 | 0.20x |
| 5 | 极限 | 快到底 | 0.18x |
| 6 | 单声道混响 | 拖尾失去立体宽度，再快近一倍 | 0.13x |

两种处理模式：**逐词**（保留每个词的差异）与**整句**（整轨只处理一次，
长广播明显更快）。实测可叠加：只改整句约 2.1x、只提最高档约 2.5x、
两者同时约 2.8x。

### 3. 完整 HTTP API

`/api/v1` 下 15 个接口，网页能做的事都能用代码完成：健康检查、素材列表、
拼写检查、时间线解析、合成 WAV、播放控制、读写参数与预设。
另附 Python 客户端，支持进程内与远程两种模式、方法名一致。

统一 JSON 信封，支持 API Key 鉴权与中英语言协商。

### 4. 进度反馈

导出与播放都会推送**真实进度**，进度条按阶段与耗时推进：
解析文本 → 应用空间效果 → 混音写盘 → 播放中。关掉空间效果时整条合成很快，
进度条也做了补间，不会一闪而过。

### 5. 前端拆分与中英双语

- 主界面从服务端拼装改为独立静态文件，逻辑与样式分离
- 中英双语：界面、帮助文档与终端日志都可切换，跟随浏览器语言
- 新增 HTTP API 参考文档

### 其他改进

| 项 | 说明 |
|---|---|
| `[preset:名字]` | 预设互相引用，带循环引用检测 |
| `[channl:偏移] … [channl:stop]` | 区块级声道偏移，最多三位小数 |
| `[alert]` 移除 | 0.2 / 0.3 有，本版删除 |
| 设置持久化 | 落盘保存，关掉程序不再丢失；按次覆盖不落盘 |
| 文件句柄泄漏修复 | 不再刷 `ResourceWarning` |
| 静态资源缓存 | 不再被浏览器缓存住旧版本 |
| 详细输出 | 逐词显示「实际听到的内容」 |

## 所有版本通用：音频素材

**三个版本都不含音频素材，都必须单独下载。** 缺素材时程序无法生成任何广播。

```bash
cd CASSIE语音生成
python cassie_download.py
```

下载器从素材仓库 [BlueArchive-ba/CASSIE](https://github.com/BlueArchive-ba/CASSIE)
的 `v1.3.0` 发布获取 `cassie.zip`（约 424 MB），支持多线程与断点续传，
网络受限时自动改用镜像。

> 下载器是 V 1.0.0 时期随「音频素材与代码分离」一同加入的，
> 但 **V 0.2 / V 0.3 同样需要它**——它们的音频也不在包里。

素材会安装到程序目录下的 `cassie/`：

```
cassie/
├── words/    单词、数字、字母音、故障音
├── sounds/   铃声与背景铃声
└── alarms/   警报音频
```

**程序会主动检查素材是否就位**（1.0.0 具备）：

| 时机 | 表现 |
|---|---|
| 启动服务 | 终端打印红框提示，含期望目录与下载命令 |
| 打开网页 | 页面上方显示提示条并给出完整路径 |
| 运行诊断 | 输出专门的提示块 |

0.2 / 0.3 没有这套提示，缺素材时只会在终端报「未找到」——
所以**先跑下载器**再启动。

## 该选哪一版

- **用最新功能** → V 1.0.0（HTTP API、中英双语、进度条、七档混响、反馈网络音质）
- **要低配环境** → V 0.2 只需 Python 3.6.5，但没有指令扩展与任何 API
- **只要基础功能** → V 0.3 是 0.2 的补全版，仍无 API 与双语

三个版本的**素材格式与指令语法高度兼容**，预设文件可以直接搬用。
